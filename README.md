# SozQor 4.0

Ағылшын сөздерін ойнап үйрететін, баттлға түсетін мобильді қосымша.
Қазақша және орысша сөйлейтіндерге арналған.

## 4.0-дегі дизайн жүйесі

3.0 бүкіл экранды градиент карталардан құрастыратын — бәрі бірдей айқайлап
тұрғандықтан «қазір нені басу керек» деген сұрақ жауапсыз қалатын. 4.0 соны
төңкерді:

* Бет тыныш (`#F7F6FB`), контент — ақ карта + жұқа жиек (`#ECEAF4`).
* **Бір экранда бір ғана қара блок** (`#15132A`) — фокус сәті: бүгінгі жоспар,
  сұрақ, нәтиже. Қалғаны бәсең.
* Басылатын нәрсенің бәрі физикалық: 4 пиксель «ерні» бар, саусақ астында
  сол ерінге батады (`SqLip`).
* Сан — прозаның бір бөлігі емес: ұпай, таймер, рейтинг, XP және кіші
  бас әріпті тақырыпшалар Space Grotesk-пен (`SqNum`, `SqEyebrow`).
* Иконка — Phosphor, эмодзи интерфейсте жоқ.

Бүкіл кит `lib/core/widgets/sq.dart` ішінде, түстер `app_colors.dart`-та
төрттіктермен (solid / deep / soft / line) жинақталған.

тегін тарифке миграция қоспайды. XP-дің өзі бұрынғыдай Supabase-те.

### Екі тіл — қазақша және орысша

Интерфейс тілі `lib/core/i18n/` ішінде:

| Файл | Не істейді |
|---|---|
| `l10n.dart` | `tr()`, `trp()`, `langProvider`, `AppLang` |
| `ru.dart` | орысша аудармалар кестесі (kk → ru) |

**Кілт — қазақша жолдың өзі.** Сондықтан аударма табылмаса, экранда
идентификатор емес, оқылатын қазақша мәтін қалады.

```dart
tr('Сақтау')                              // → «Сохранить»
trp('{n} сөз қалды', {'n': '$left'})      // → «осталось 7 слов»
```

`providers.dart` осы файлды қайта экспорттайды, сондықтан оны импорттаған
кез келген экранда `tr()` дайын тұрады.

Тіл **Баптаулар → Тіл → Қосымша тілі** арқылы ауысады және бірден,
қосымшаны қайта қоспай-ақ қолданылады: әр экран `ref.watch(langProvider)`
жасайды. Таңдау құрылғыда (`shared_preferences`) және профильде (`ui_lang`)
сақталады; құрылғыдағы таңдау әрқашан басым.

Жаңа жол қосқанда: жазуды `tr('...')`-қа орап қой да, `ru.dart`-қа сол
қазақша кілтпен орысша нұсқасын қос. `flutter test test/i18n_test.dart`
placeholder-лердің екі тілде де сәйкес келетінін тексереді.

### Авторизация

Телефон + құпия сөз. Нөмірді қолданушы қолмен жазбайды — Telegram ботына
бөліседі, бот `contact.user_id == from.id` екенін тексереді, сол растау болып
саналады. Supabase-те аккаунт `<нөмір>@sozqor.kz` түрінде сақталады.

Қонақ режимі анонимді сессиямен істейді; тіркелгенде `user id` өзгермейді,
сондықтан бүкіл прогресс сақталады.

### SozQor AI — өз сөздік миымыз

Аударма 4 қабаттан өтеді, бірінші тапқанда тоқтайды:

1. **Сессия жады** — лезде, тегін
2. **Офлайн сөздік** — `assets/data/starter_dictionary.json`, интернетсіз істейді
3. **Ортақ база** — `dictionary` кестесі, барлық қолданушының сұранысынан өседі
4. **LLM** (OpenRouter → Gemini) — жауап **мәңгілікке** 3-қабатқа жазылады

Яғни бір сөзді біреу бір рет сұраса, ол бүкіл қосымша үшін тегін болады.
`sozqor-grow` бұған қоса күнделікті жаңа сөз пакеттерін базаға қосып отырады.

## Деректер қоры

```
profiles          аккаунт, деңгей, XP, Elo, серия, тіл баптаулары
dictionary        ортақ сөздік (en / kk / ru + мағына, синоним, антоним)
words             қолданушының жеке сөздері + қайталау кестесі (SRS)
battles           жекпе-жек (ranked / bot / friend)
mm_queue          матчмейкинг кезегі
leagues           апталық лига (30 адам, топ-10 жоғарылайды)
tournaments       24 сағаттық турнир
daily_results     күнделікті глобал сынақ
game_scores       марафон / тайм-атака рекордтары
events            сервер жағынан қосылатын іс-шаралар
achievements      22 жетістік (кодта, `game_meta.dart`)
```

## Ойын режимдері

**Жалғыз:** Классикалық тест · Қайталау (SRS) · Марафон (3 жан) ·
Тайм-атака (60 сек) · Күнделікті глобал сынақ

**Жарыс:** Рейтингті 1v1 (realtime + Elo) · Ботпен · Доспен (код арқылы) ·
Лига · Турнир

**Сұрақ түрлері (деңгейге қарай ашылады):** ҚАЗ→АҒЫЛ · АҒЫЛ→ҚАЗ · Мағына ·
Синоним · Антоним · Тыңдау · Емле · Сөйлем

## Іске қосу

```bash
flutter pub get
flutter run
```

Баптау қадамдары (Firebase кілттері, iOS конфигі, AI құпиялары) —
`SETUP.md` файлында.

## Жоба құрылымы

```
lib/
  core/          тема, түстер, мәтіндер, ортақ виджеттер
  data/          модельдер, репозиторийлер, Supabase клиенті
  services/      SozQor AI, сұрақ фабрикасы, TTS, push, жетістіктер
  features/      auth · onboarding · home · words · play · arena · profile
supabase/
  functions/     Edge Functions бастапқы коды
```

`lib_old/` — 2.0 нұсқасының (Firebase) мұрағаты, талдаудан шығарылған.
Керек болмаса жойып жіберуге болады.
